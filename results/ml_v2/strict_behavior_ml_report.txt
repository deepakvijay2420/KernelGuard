KernelGuard Strict Behavioral ML Experiment
============================================

Purpose:
Evaluate whether attacks can be distinguished using policy-independent behavioral and temporal telemetry.

Excluded features:
- risk
- reason
- action
- task_id
- attack_id
- label
- exact executable identity

Group-aware train/test split was used to prevent run-level leakage.

Important interpretation:
These results measure behavioral classification on the current controlled dataset. They should not be interpreted as proof of generalization to unseen real-world attacks.
